# LogHunter v2.1 Backnote

Date: 2026-10-23 (updated 2026-10-27)

Use this note when drafting the next `v2.1` release summary.

## Carry forward from v2.0.0.1

- ALB region detection from the S3 bucket name no longer picks up `af-` / `ca-` fragments inside the bucket GUID (for example `af-us-east-1` instead of `us-east-1`), which made ALB listing and download fail for affected buckets. Fixed in both web shell and console flows.

## Carry forward from v2.0.0.2

- ALB download page no longer sticks on a previous job's status when a second download is started right after the first; a second Start while one is running switches the page to the running job.
- Start download returns immediately; the AWS CLI checks run in the background job.
- New `--trace` / `--debug` launch option writes a JSON-lines trace of every web request, browser action, ALB job step and AWS CLI call to `logs\trace-<timestamp>.jsonl`, with credentials masked.
- IIS Burst Patterns severity colors follow the severity score (CRIT and MED rows colored again).
- ALB download empty-listing error suggests checking the Sentry toggle.

## Suggested short release-note wording

- Fixed ALB region detection for S3 buckets whose GUID produced an invalid region, which caused `aws s3 ls failed` during ALB downloads.
- Fixed the ALB download page showing a previous job's status after starting a new download.
- Added `--trace` launch option for recording a full session trace for troubleshooting.
- Fixed IIS Burst Patterns severity colors.
