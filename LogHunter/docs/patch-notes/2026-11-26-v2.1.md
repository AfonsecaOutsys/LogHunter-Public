# LogHunter v2.1

Date: 2026-11-26

LogHunter 2.1 rolls up the 2.0.0.1 -> 2.0.0.5 patch line (folded in from `2026-10-23-v2.1-backnote.md`) and adds the fixes from the 2.0.0.5 QA walkthrough and re-check (`qa-walkthrough-2.0.0.5.md`, `handoff-qa-fixes-2.0.0.6.md`, `qa-recheck-2.0.0.6.md`). The planned 2.0.0.6 hotfix ships as 2.1.

## New in 2.1

### Log sources and inputs

- IIS Status Pivot, Top Bandwidth and Uploads / Payloads accept default folder, selected folder or selected files (shared `IisSourceFiles` resolver, same rules as Burst Patterns) and show `<folder> | N files | size` before a run.
- Platform suspicious and authenticated pages show the PlatformLogs folder, CSV/XLSX file count and size.
- `--root` now moves every workspace folder: `AppFolders` paths are properties resolved from `UseRoot`, not fields frozen at the exe folder.
- One parser for manual IP lists (`IpTargetParser.ParseIpList`): IP Summary (ALB and IIS), Requests over time, AbuseIPDB and Platform authenticated activity. Full dotted quad required, normalised, de-duplicated; invalid tokens come back as `ignored` and show as "Ignored input". The extractor for IPs read from files uses the same strict check.
- AbuseIPDB: private, loopback, CGNAT, link-local and multicast/reserved addresses are listed as `skipped` and never sent. Private IPs are also dropped from the reputation hand-off.

### Results and accuracy

- Requests over time: Open chart button and top-buckets table visible again (regression from the global `[hidden]` fix). The "Ignored input" note survives the chart auto-open.
- ALB Top 50 IPs / by URI / AVG duration count pills show unique IPs, IP+URI pairs and URIs, formatted.
- AVG duration and Top 50 by URI (and WAF blocked pairs) normalise paths: trailing `/` trimmed (not root), case-insensitive. On the QA set: 835 -> 807 URIs, 1,392 -> 1,385 pairs; top rows unchanged.
- Uploads: ranked and labelled by largest single upload (`MaxBytes`), with total `cs-bytes` and POST/PUT count.
- Platform suspicious scan: rows matched without a client IP, unparsed rows and skipped files (with reason) are reported; completion message no longer says "no matches" when rows matched.
- Platform authenticated activity: `net.host.ip` is the server, not the client; Integrations and Service Actions exports are reported as "Skipped (no client IP column)". Counts formatted (`6,554`).
- ALB IP Summary: CDN / proxy badges, FE "no response" row so FE totals add up.
- Per-IP cards and the HTML report default selection sorted by hits, not by IP string.
- Charts (web and HTML reports): y-axis never below 0, last x label kept inside the chart.
- IP sweep: CIDR / range targets show the report's network label ("Akamai edge (6 IPs)"), IPs column shows 1 for a single match; folder label inputs styled.
- IP ranges page lists the built-in ranges (Google Cloud LB, Sucuri, Netskope) with a "built-in" row.
- ALB Top IPs + paths: top IPs rendered as a table.

### Copy and layout (guardrails)

- Duplicate hero blocks removed: page title and description appear once, in the header; inputs sit higher.
- Roadmap / scaffolding wording removed (landing descriptions, placeholder pages, "per current definition", "downstream use").
- Errors shown without the `Error:` prefix; the status filter error names the bad codes and the expected format.
- "Open Excel" on IIS Bandwidth / Uploads exports; "1 file" pluralisation; documentation-range example IPs; "Bucket (UTC)"; neutral style for "Ignored input" notes.

### Feedback, usage counts and trace

- Feedback page posting to the LogHunterUsage feedback endpoint (always sends; not affected by the usage switch).
- Anonymous usage counts On / Off switch under the feedback form, saved in `config\usage-settings.json`, on by default; `LOGHUNTER_NO_USAGE=1` still forces off.
- Usage trace lines carry the session id; the `/api/app/info` heartbeat is no longer traced (server and browser), which removes most trace volume.

### Tests

- 168 tests. New: `PlatformScannerTests`, `PlatformAuthScannerTests`, `AlbGenericScanFunctionsTests`, `IisSourceFilesTests`, `AppFoldersTests`, `FeedbackSenderTests`, `ParseIpList` cases. Tests touching the shared `IpIntelStore` snapshot run in one xUnit collection (fixes a flaky parallel failure).

## Folded in from the 2.0.0.x line

### 2.0.0.1

- ALB region detection from the S3 bucket name no longer picks up `af-` / `ca-` fragments inside the bucket GUID, which made ALB listing and download fail. Web shell and console.

### 2.0.0.2

- ALB download page no longer sticks on a previous job's status; a second Start while one runs switches to the running job. Start returns immediately; AWS CLI checks run in the background job.
- Always-on diagnosis trace in `logs\trace-<timestamp>.jsonl`, credentials masked, 10-day retention.
- IIS Burst Patterns severity colors follow the score; ALB empty-listing error suggests the Sentry toggle.

### 2.0.0.3

- IIS Burst Patterns: one scoring engine shared by console and web; bursts flagged only with real threat signals; Scan campaigns panel groups rotating-IP scans; column tooltips, highlighted 4xx%.

### 2.0.0.4

- IP sweep (ALB and IIS): unlimited IPs, CIDR blocks and ranges across several folders, customer-safe HTML report and Excel, hand-offs to IP Summary and AbuseIPDB.
- CDN and proxy range intelligence refreshed in the app, IP ranges pill and page, customer-pasted ranges; badges and "Fronted by" banner in ALB and IIS results.
- IIS client IP read right to left through X-Forwarded-For skipping CDN edges; ClaimedClient and X-Forwarded-For export columns.
- ALB Start download locked while a job runs.

### 2.0.0.5

- Anonymous usage counts: one event per launch and per workflow run (install id, launch id, version, mode, workflow name only), background and silent on failure.

## Not in 2.1

- Burst Patterns thresholds unchanged (QA item D2 left as designed).
- ALB download not re-tested in this cycle.
